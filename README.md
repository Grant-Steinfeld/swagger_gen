# African Pet Store API

This project is a Node.js Express API written in TypeScript for a pet store selling Dogs, Cats, and Tropical Fish, focusing on African breeds and types. All endpoints are validated with Joi middleware. Unit tests are written using Jest and Supertest.

## Features
- Express API with routes for Dogs, Cats, and Tropical Fish
- Joi schema validation for all endpoints (GET, POST, PUT, PATCH, JSON bodies)
- TypeScript for type safety
- Jest and Supertest for endpoint unit testing with mock data

## Scripts
- `npm run dev` — Start the server in development mode
- `npm test` — Run all tests

## Getting Started
1. Install dependencies: `npm install`
2. Start the server: `npm run dev`
3. Run tests: `npm test`

## Project Structure
- `src/` — Source code (Express app, routes, middlewares, models)
- `tests/` — Jest/Supertest unit tests

## African Breeds/Types
- **Dogs:** Basenji, Africanis, Boerboel
- **Cats:** Egyptian Mau, Abyssinian, Sokoke
- **Tropical Fish:** African Cichlid, Congo Tetra, Elephantnose Fish
